# 📚 Book Shop Automation Software

A full-stack web application that automates and simplifies book store operations with features like inventory management, sales tracking, customer records, and report generation.

🔗 **Live Demo**: [book-shop-automation-software.vercel.app](https://book-shop-automation-software.vercel.app/)

---

## 🚀 Features

- 📦 Inventory Management  
- 💰 Sales & Billing  
- 👥 Customer Tracking  
- 📊 Analytics & Reports  
- 🖥️ Responsive UI

---

## 🛠️ Tech Stack

- **Frontend**: Next Js, Tailwind CSS  
- **Backend**: Next Js
- **Database**: MongoDB  
- **Authentication**: NextAuth  
- **Deployment**: Vercel

---

## 📦 Installation & Setup

### 1. Clone the Repository
```bash
git clone https://github.com/Sandeep-622/Book-Shop-Automation-Software.git
cd Book-Shop-Automation-Software
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Create a `.env` File
Create a `.env` file in the root directory and add the following variables:

```env
JWT_SECRET=your-secure-secret-here
MONGO_URI=your-mongodb-uri
NEXTAUTH_SECRET=your-random-secret
NEXTAUTH_URL=http://localhost:3000
```

### 4. Run the Development Server
```bash
npm run dev
```

The app will be running at [http://localhost:3000](http://localhost:3000)
